## 为什么要写博客

写博客是一件很有意义的事情。通过写作，我们可以：

- **整理思路**：把模糊的想法变成清晰的文字
- **记录成长**：回顾过去的自己，看到进步和不足
- **分享知识**：帮助到有同样问题的人

## 这个博客的技术栈

这个博客使用了非常简洁的技术方案：

```python
# 后端
from fastapi import FastAPI
app = FastAPI()

# 文章内容用 Markdown 编写
# 无需数据库，文件系统就是最好的数据库
```

选择这个方案的原因：

1. **写作体验好** — Markdown 专注于内容
2. **部署简单** — 一个 Python 进程搞定
3. **版本管理** — 用 Git 管理文章
